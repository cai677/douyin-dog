# 剪映朗读音频字幕轨

支持飞书拆解文档生成剪映草稿，以及直接文案生成逐句朗读音频两种场景。草稿只包含朗读音频轨和字幕轨，不处理画面素材。

## 适用场景

使用本 skill 当用户要求：

- 根据飞书拆解文档生成剪映草稿；
- 直接提供文案和音色，按标点分句，试听1.2、1.3、1.4倍速后完成朗读；
- 只生成朗读音频轨和字幕轨；
- 使用豆包/火山语音 TTS；
- 一句文案对应一个独立朗读音频片段；
- 所有句子的朗读倍速一致；
- 去掉每句开头多余气口。

如果用户要求拆解视频、抽帧、生成带图片分镜文档，应使用带货视频拆解 skill，而不是本 skill。

## 直接文案配音场景（2026-09-15）

用户只提供整篇文案并选择音色时，读取并执行 [直接文案与倍速试听流程](references/text-audition.md)。不要求飞书文档或参考时间轴。

按标点逐句断行，去掉断行文案中的标点，先确认音色名称、完整ID和配音要求；试听阶段仅生成前三个非空断句（不足三句则全部），每句裁掉首尾多余气口，再从同一裁后原音频制作1.2x、1.3x、1.4x保音高试听。前三句各提供三个倍速版本，等用户选定统一倍速后才生成剩余句子，完成全篇独立逐句朗读。不得提前生成全篇试听。连续试听仅作补充。

本场景以该流程为准，不套用下文旧版飞书专用的连续重复去重、只裁句首、强制原总时长或必须制作草稿要求。旧版voice_draft.py尚无直接文案和三档试听入口；规范已定义不代表脚本已实现或音频已生成。

## 配音前必须确认（用户长期要求，2026-09-15）

每次新配音任务开始生成前，先向用户列出并确认以下内容，再继续配音及后续草稿制作：

- 每个文档/版本对应的音色名称和完整音色ID，两者同时展示，不能只用“03音色”等临时编号。
- 配音要求：文案版本及修改权限、朗读范围、语速/倍速、语气（未指定则说明采用音色默认）、句首句尾气口与自然停顿、目标时长及是否允许随真实配音缩短。
- 复用已确认气口标准时明确写出“复用哪个音色的已确认标准”。历史标准可作为本次建议，但不自动代替本次任务确认。

信息不全时先整理现有文案与建议，集中确认。等待确认期间可做读取和准备，不调用TTS（包括试听生成）或推进依赖配音设置的草稿制作。当前任务中已明确确认的同一套设置不重复询问；更换音色名称/ID或改变配音要求时，先确认变更。音色不可用时不能自动换音色。

## 紧凑气口规则（2026-09-15）

用户要求收紧头尾气口、减少留白时，采用本节；优先于下文旧版“60ms句首、不裁句尾、强制原总时长”约束。

- 句首保留20ms，句尾保留60ms。低声起音或拖尾有误切风险时局部增加缓冲并记录，不能只为变短切掉发音。
- 使用10ms窗RMS、起步门限-42dBFS、连续三窗中至少两窗有效；不能把单个越过阈值的杂音点当作起声。低电平不等于无语音，门限是启发式而非语音识别。
- 用 `scripts/compact_audio.py <输入.wav> <新输出.wav>` 裁两端并保存采样区间记录。它只处理PCM16单声道WAV，保留句中音频；不自动裁掉句中轻声或呼吸。
- 修订已有草稿时保持修订前统一倍速，按裁后真实长度连续排列音频和字幕，允许总时长缩短。禁止通过降速、补空白或拉长字幕把移除的停顿填回去。必须保持原时长的任务另行确定节奏方案。
- 默认每句独立WAV，不合并交付；只改用户指定草稿，原稿另存备份，不覆盖用户手工编辑稿。字体遵循当前用户指定。
- 保存每句前后留白、移除秒数、源采样区间和时间轴；检查首字、尾字、长停顿及字幕对齐。数值检测通过不能替代试听，未试听明确标记。
- `voice_draft.py` 是旧版入口，尚未集成本节的双端裁剪和时间线规则，不得直接运行并声称完成紧凑模式；应调用新裁剪器并按本节重建时间线。

## 已验证约束

- 飞书文档必须包含可解析文案表格。优先读取第六段“逐句文案时间轴”里的 `时间` 和 `文案` 列；如果第六段缺失或不可解析，再回退读取表头里的 `时间` 和 `台词`/`口播文案`/`字幕`/`文案` 列。
- 若文档来自 `daihuo-video-breakdown`，优先读取第六段“逐句文案时间轴”表格；该表格列顺序固定为：序号 / 时间 / 文案。第五段“完整分镜脚本”只作为回退来源，列顺序固定为：镜号 / 时间 / 时长 / 景别 / 台词 / 画面帧 / 音效。
- 如果文档没有单独 `视频时长 | XX.XX 秒` 字段，用实际读取到的文案表格最后一行 `时间` 的结束点作为总时长；如果解析不到时间列或文案/台词列，先回到拆解文档补齐交接字段。
- 连续重复文案只朗读一次；非连续重复保留。
- 如果文档有单独视频总时长且大于表格最后一行结束时间，则最后一句延长到视频总时长。
- 每句文案单独生成 WAV，不合并为一条总音频。
- 每个 WAV 重写标准 WAV 头，避免剪映解析异常。
- 每句只裁剪句首静音，保留约 60ms 缓冲；不裁剪句尾。
- 所有音频片段使用同一个统一倍速。
- 字幕按飞书表格时间轴排列。
- 字幕字体名写入“抖音体”，字号写入 9。

## 验收标准

生成后检查：

1. 剪映草稿能打开。
2. 音频轨是多段独立 WAV，不是合并 MP3 或合并 WAV。
3. 音频片段数等于字幕片段数。
4. 所有音频片段的 speed 完全一致。
5. 草稿总时长等于飞书文档视频总时长；若文档未单独标注视频时长，则等于实际读取到的文案表格最后一行结束时间。
6. 连续重复文案没有重复朗读。
7. 每句起声没有明显句首空白。
8. 字幕显示为抖音体、9 号；若本机缺字体，剪映可能回退，需要人工确认。
